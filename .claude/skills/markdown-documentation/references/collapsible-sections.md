# Collapsible Sections

````markdown
<details>
<summary>Full package list</summary>

Hidden content goes here.

- Can include lists
- Code blocks
- Images

```bash
readonly FOO="bar"
```

</details>
````

## Syntax Highlighting

Put the language after the opening fence. Common ones: `javascript`,
`typescript`, `python`, `bash`, `java`, `go`, `rust`, `sql`, `json`, `yaml`,
`html`, `css`, `dockerfile`, `graphql`, `markdown` and `text` for plain output.
