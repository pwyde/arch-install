# AGENTS.md: dots/.config/niri/

niri configuration, copied to `~/.config/niri/` by `desktop-install.sh`. The
root [AGENTS.md](../../../AGENTS.md) applies as well.

- `config.kdl` includes each `config.d/` file by name; add a new file to that
  list. `noctalia.kdl` is generated by Noctalia and included as optional,
  before `90-user-extra.kdl`.
- `config.d/90-user-extra.kdl` stays comments-only. `desktop-install.sh`
  restores it on every run and appends the blocks generated from the
  keyboard and display options.
- The US bindings in `config.d/70-binds.kdl` and their commented Swedish
  alternatives must match the `pairs` in `configure_swedish_binds` exactly,
  or the swap is skipped with a warning.
